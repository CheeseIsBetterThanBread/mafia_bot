# Добавление новой команды

## Технические детали

- Новую команду нужно добавить в enum `QueryType` [здесь](../connection/queries.py)

- Возможно, ей понадобится новый тип запроса, его следует дописать в [events.py](../connection/events.py)

- Описание команды можно сразу добавить в [текст с помощью](../config/help.py)

--- 

## Реализация со стороны сервера

После добавления команды по шагам выше, нужно добавить её обработку сервером.
Для этого нужно написать новый метод класса `EventDispatcher` и в его методе
`handle` повесить этот обработчик на тип новой команды

Все это можно найти в файле [dispatcher.py](../engine/dispatcher.py)

---

## Поддержка адаптером

Теперь можно в адаптере поддержать новую команду. 
В ней по сообщению будет строиться запрос, который отправится на сервер

---

## Проверка работы

Тесты надо писать в зеркальные файлы.
Тут трудно выделить какую-то отдельную часть, затрагивается много файлов.
Скорее всего надо будет прогнать тесты целиком

```bash
make test
```

---

## Рекомендации

* Не хранить глобальное состояние
* Не вызывать другие команды напрямую
* Общаться только через события
* Делать команды маленькими
