Под конфигом здесь понимается файл [settings.py](../config/settings.py)

## Переменные окружения

Переменные окружения настраиваются в `.env` файле и загружаются с помощью `load_dotenv`.
Подробнее про настройку `.env` можно почитать в разделе [про запуск проекта](setup.md)

Они отвечают за то, чтобы код смог обратиться к вашему боту через api сервиса.
Разные адаптеры требуют разных переменных, чтобы узнать, как их достать, обратитесь к интернету

## `CACHE_TTL_SECONDS`

Была добавлена для настройки кеша при поиске имён в вк, но может использоваться для произвольных кешей

Через заданное время считается, что кеш уже не валидный, так что надо делать новый запрос к api

## Дневные таймеры

Регулируют время, которое отводится каждому игроку на дневную речь

Время считается динамически: число живых игроков умножается на `SECONDS_PER_PLAYER`.
Потом оно редактируется так, чтобы попасть в окно [`SPEECH_LOWER_BOUND`, `SPEECH_UPPER_BOUND`].
За `WARNING_OFFSET` секунд до конца отведённого времени будет выслано предупредительное сообщение

---

## Ночные таймеры

Регулируют время, которое отводится игрокам на совершение выбора ночью

Вор ночью ходит первым, на это у него есть `THIEF_TIME` секунд. 
Если вор мёртв, то бот подождёт $n \in$ [`THIEF_LOWER`, `THIEF_UPPER`] секунд и объявит,
что вор никого не заклеил

Остальным игрокам отводится `NIGHT_TIME` секунд.
Причём за `REMINDER_OFFSET` до конца будет выслано предупреждение

## Логирование

Здесь можно настроить, куда и в каком формате будут писаться логи

Переменные `CONFIG_DIR` и `ROOT_DIR` менять не надо,
они по относительным путям находят положение корневой папки

Задать другое название папки с логами можно с помощью переменной `LOGS_DIR`,
название файлов - `LOG_FILE`

Переменные `MAX_BYTES_PER_FILE` и `BACKUP_FILES` отвечают за то,
сколько логов может одновременно храниться на устройстве. 
Всего будет не более `BACKUP_FILES + 1` файлов, 
каждый из которых весит не больше `MAX_BYTES_PER_FILE` байтов

Формат логов можно задать через `LOG_FORMAT`
