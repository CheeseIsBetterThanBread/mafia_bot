# Работа с Makefile на Windows

## Вариант 1 — Git Bash

Установите:

* Git for Windows

Используйте Git Bash:

```bash
make run
```

---

## Вариант 2 — WSL

Установите:

```powershell
wsl --install
```

После установки:

```bash
sudo apt install make
```

---

## Вариант 3 — mingw32-make

Установите MinGW.

Иногда команда называется:

```bash
mingw32-make
```

Тогда:

```bash
mingw32-make run
```
--- 

С другими вариантами можно ознакомиться [здесь](https://config-cli-gui.readthedocs.io/en/latest/develop/make_windows/)
